# CareerOS Vision

> Treat your career like software. Version it. Build it. Evolve it.

## Vision

CareerOS is an open-source platform inspired by Platform Engineering and GitOps principles that treats professional career information as code.

Instead of maintaining resumes, LinkedIn profiles, portfolios, interview stories, and personal websites independently, CareerOS establishes a single source of truth capable of generating multiple professional artifacts automatically.

Our long-term vision is to become an operating system for engineering careers.

## Mission

Help software professionals manage their careers with the same discipline used to build modern software platforms.

## Problem

Professional information is fragmented across multiple systems. The same facts and achievements are copied into resumes, LinkedIn, portfolios, application forms, and interview notes. This creates duplicated work, inconsistent wording, outdated content, and limited traceability.

## Solution

CareerOS introduces **Career as Code**:

- Professional data is declared once.
- Data is version-controlled and validated.
- Outputs are generated through reusable templates.
- Public and private information remain explicitly separated.
- Changes are reviewable and reproducible.

## Core Principles

1. **Single Source of Truth** — professional information should exist once.
2. **Configuration as Code** — career data is structured and declarative.
3. **Documentation First** — important decisions are documented before implementation.
4. **Automation by Default** — repetitive work should become automated.
5. **Platform Thinking** — one domain model should support multiple outputs.
6. **Open by Design** — generators and templates should be extensible.
7. **Privacy by Design** — the engine must not require public exposure of personal data.

## Target Audience

The first audience is software engineers, platform engineers, DevOps and SRE professionals, software architects, and technical leaders.

## Non-Goals

CareerOS is not intended to replace LinkedIn, applicant tracking systems, or professional networking platforms. It is not a credential store and should not contain secrets or confidential company information.

## Success Criteria

CareerOS succeeds when a professional can update one trusted source and regenerate consistent, role-relevant career artifacts with confidence.
